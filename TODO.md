## Функциональность

- [ ] **Учёт разного времени торгов у акций и фьючерсов**
  Акции торгуются с 7:00 МСК, фьючерсы — с 9:00. В промежутке 7:00–9:00 спред
  считается по устаревшей цене фьючерса.
  Варианты решения:
  - Отображать время последней сделки в таблице.
  - Не считать спред, если цена старше N минут.
  - Синхронизировать сессии — учитывать только общее торговое окно.

- [x] **Проверить источник цены для фьючерса**
  Выполнено в 0.4.1 — добавлен `Depth: 1`, цена берётся из `bids[0]`
  (лучшая заявка на покупку). Индикатор источника отображается в веб-интерфейсе.

- [ ] **Автозамена фьючерсов после экспирации**
  Когда у фьючерса остаётся 0 дней до экспирации, автоматически подбирать
  следующий контракт (экспирация > 0 и < 3 месяцев) и обновлять пару

- [ ] **Фиксация цены одной или обеих ног («заморозка»)**
  Сценарий: одна или обе ноги уже открыты по известной цене. Нужно зафиксировать
  эту цену, чтобы она не обновлялась из API. Вторая нога (если не зафиксирована)
  продолжает торговаться, спред и доходность пересчитываются в реальном времени.

  Три режима:
  - **Только акция** зафиксирована → фьючерс обновляется.
  - **Только фьючерс** зафиксирован → акция обновляется.
  - **Обе ноги** зафиксированы → калькулятор (ничего не обновляется, можно
    посчитать гипотетическую сделку).

  Что нужно:
  - **Хранение:** добавить колонку `fixed_price REAL` в таблицу `instruments`
    (по одной на инструмент). `NULL` — цена обновляется из API, значение —
    используется фиксированное. Снять фиксацию = установить `NULL`.
    Если позже понадобится разная фиксация одной акции в разных парах —
    перейти на хранение в таблице `pairs` (поля `stock_fixed_price`,
    `future_fixed_price`).
  - **Ввод:** модальное окно на сайте. Кнопка (например, 🔒 или `F`) в каждой
    строке таблицы. В окне два поля — цена акции и цена фьючерса.
    Пустое поле = не зафиксировано. Кнопки «Сохранить» и «Снять фиксацию».
  - **API:** HTTP POST-эндпоинт на сервере (`/api/fix`), который обновляет
    `fixed_price` в БД. После сохранения — WebSocket рассылает обновление
    всем клиентам.
  - **Индикатор на сайте:** показывать значок «зафиксирована» рядом с ценой
    (например, `f` или `🔒`), аналогично индикатору источника цены.

  Связанные изменения:
  - `updater.go` — перед вызовом `GetBestPrices` проверять `fixed_price`
    для каждого инструмента; если задано — использовать его.
  - `web/index.html` — модальное окно + индикатор.
  - `internal/webserver/server.go` — новый HTTP-эндпоинт `/api/fix`.
  - `internal/db/db.go` — методы для чтения/записи `fixed_price`.

- [ ] **Редактирование комиссий и пар на сайте**
  В будущем — возможность менять `commission_stock`, `commission_future`
  и добавлять/удалять пары прямо из веб-интерфейса.

- [ ] **Флаг «реинвестирование дивиденда» в конфиге**
  Добавить параметр `dividend_reinvest: true / false` в `config.yaml`.
  Если `true` — при расчёте доходности вычитать очищенный дивиденд
  из инвестированного капитала: `investedCapital = priceStock − dividendNet + goPerShare`.
  Если `false` — использовать полную стоимость акции: `investedCapital = priceStock + goPerShare`.
  Смысл: при покупке перед отсечкой дивиденд приходит через 1–2 недели
  и может быть реинвестирован, поэтому на большую часть срока ты морозишь
  меньшую сумму. Для бездивидендных акций и коротких сроков разницы нет.

- [ ] **Автоопределение уровня риска (КПУР/КСУР) через API**
  Проверить, возвращает ли API Т-Инвестиций информацию о уровне риска
